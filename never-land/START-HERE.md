## 1️⃣ شغّلها الآن (وضع المعاينة)

اللوحة تعمل حاليًا ببيانات تجريبية على المنفذ **3000** — افتح المعاينة في المتصفح لتتصفّح الواجهة:

```bash
npm install        # مرة واحدة
npm run web        # لوحة التحكم فقط (بدون بوت)
```

---

## 2️⃣ اربط بوتك الحقيقي

1. افتح [`Discord Developer Portal`](https://discord.com/developers/applications) → **New Application**.
2. من تبويب **Bot**:
   - انسخ **Token**.
   - فعّل ✅ **SERVER MEMBERS INTENT** و ✅ **MESSAGE CONTENT INTENT**.
3. من **OAuth2 → General**: انسخ **Client Secret** وأضف **Redirect**:
   `http://localhost:3000/auth/callback`
4. عدّل ملف `.env`:

```env
DISCORD_TOKEN=التوكن_هنا
CLIENT_ID=الآيدي_هنا
CLIENT_SECRET=السر_هنا
DEMO_MODE=false          ← مهم: أوقف وضع المعاينة
SESSION_SECRET=نص_عشوائي_طويل
```

5. شغّل:

```bash
npm start        # البوت + اللوحة معًا
```

6. ادعُ البوت لسيرفرك بصلاحية **Administrator** (أو الصلاحيات المطلوبة)،
   وتأكد أن **رتبة البوت أعلى من رتب الأعضاء**.
7. أوامر السلاش تُسجَّل **تلقائيًا وفورًا** عند تشغيل البوت.

## 🖥️ اللوحة الجديدة
1. افتح `http://localhost:3000/dashboard`
2. اختر سيرفرك ➜ تلاقي **الشريط الجانبي**: نظرة عامة، الترحيب، الرتب، المستويات، الحماية، التذاكر، تقديم الإدارة، السجلات، البيانات
3. بدّل أي مفتاح ➜ يعطيك شريط أصفر أسفل الشاشة ➜ اضغط **💾 حفظ التغييرات**
4. تبغى تصوّر شكلها قبل التشغيل؟ افتح ملف `معاينة-اللوحة.html` (نسخة ثابتة تعمل بالنقر)

> 🔍 فيه صندوق بحث فوق القائمة: اكتب «تذاكر» أو «ترحيب» ويوصلك بسرعة.

## 🌐 موقع Never Land
- الموقع **حقيقي وليس نسخة جاهزة**: صفحات تُبنى من الخادم + واجهة API + قاعدة بيانات.
- الرابط الحالي (يُفتح من متصفح الجوال أو الكمبيوتر): يُضبط في `.env` عبر `DASHBOARD_URL`.
- ملفات الموقع الأساسية موجودة: `/icon.svg` (شعار مرسوم) • `/manifest.webmanifest` • `/robots.txt` • `/sitemap.xml` • صفحة 404 مصمّمة.
- **لتشغيله بحساب Discord حقيقي:** ضع `DISCORD_TOKEN` و`CLIENT_ID` و`CLIENT_SECRET` واجعل `DEMO_MODE=false`، ثم أعد التشغيل.

## 🔐 الدخول والرول المطلوب
- الموقع ما يفتحه إلا من **سجّل دخوله بحساب Discord**.
- بعد الدخول لازم يكون عنده **الرول المطلوب**: `1549364852433354792`.
- من ما عنده الرول يشوف صفحة «الوصول مقيّد» فيها خطوات الحصول عليه وزر إعادة الفحص.
- تغيير الرول: `REQUIRED_ROLE_ID=...` في `.env` (اتركه فارغًا لقبول أي عضو).

## 🔗 زر الموقع في /help
أرسل `/help` في ديسكورد → يطلع زر **افتح الموقع** + **لوحة التحكم**، بيفتح مباشرة في المتصفح.

## 🌍 من يقدر يفتح الموقع؟
- الوضع الافتراضي الآن: **تأكيد دخول + رول مطلوب** (الأعلى).
- لو حبيت ترجع العرض العام للزوار (قراءة فقط): اجعل `LOGIN_REQUIRED=false` و`PUBLIC_ACCESS=true`.

## 📱 على الجوال والتابلت والجهاز
- الموقع يتكيّف تلقائيًا: جوال • تابلت • شاشة كبيرة • وضع أفقي.
- السمة تتبع **إعداد الجهاز** (ليلي/نهاري) إن ما اخترت، والزر ثلاث حالات: حسب الجهاز ← نهاري ← ليلي.
- تقدر تثبّته كتطبيق من متصفح الجوال (أيقونة + مانيفست جاهز).

## 🌗 الوضع الليلي / النهاري
فيه زر في أعلى كل صفحة (أيقونة شمس/قمر مرسومة). اضغطه ليتبدّل الوضع، والاختيار يُحفظ لك في المتصفح.

> 🎨 الموقع لا يستخدم إيموجيات الكيبورد: كل الرموز أيقونات SVG مرسومة محليًا (بدون إنترنت أو مكتبات خارجية).
